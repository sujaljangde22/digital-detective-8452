## Task / Objective

Understand input, processing, output and storage; identify hardware and software; and explore everyday computer systems.

## Task 1.1 — Input, Processing, Output and Storage

Activity: Typing and saving a document

| Stage | What happens | Hardware/component involved |
|---|---|---|
| Input | I press keys to enter text into the document. | Keyboard |
| Processing | The computer interprets my keystrokes and updates the document. | CPU and RAM |
| Output | The text I type appears on the screen. | Monitor/Display |
| Storage | When I save the document, it is written to my computer’s SSD so I can open it later. | SSD |

### How the stages connect
- when i click a it takes a input into the document through keyboard, the computer interprets my keystrokes and updates the document using cpu and ram, the text is displayed on the screen on monitor/display and when i save the document it is saved on my computer's ssd.

## My Understanding
A computer recieves input, process it, gives output and sometime stores it for future use. Hardware refers to physical components, such as a keyboard, while software contains instructions that tell the computer what to do. For example, a calculator takes numbers and an operation as input, processes the calculation and displays the result as output.
