### Task 4.2 — Compare compilers and interpreters

| Point | Compiler | Interpreter |
|---|---|---|
| When it works | Translates source code before the translated code runs. | Executes program instructions at runtime. |
| Typical output | Translated code, such as an executable or bytecode. | The result of running the program, such as text printed to Terminal. |
| Example | Clang translates a C program into an executable. | Python 3 runs my `hello.py` script. |
| One advantage | I can run a compiled executable again without rebuilding it. | I can edit a script and run it again with one command. |

## Commands / Tools Used

- `python3 mission-04-programs/hello.py` ran the script from my repository folder.
- `print()` displayed the message in Terminal.

## My Understanding

A compiler translates code into another form. An interpreter executes instructions. A language implementation can use both approaches. For example, CPython compiles Python source code to bytecode and then interprets that bytecode.
